# 摄像头电脑端测试（阶段 A）

目标：**不接小车**，确认 JQ-CAM12-720P 三合一模块（摄像头 + 麦克风 + 喇叭）本身全部正常，并把以后 ESP32 端要用的视频格式参数记录下来。

## 准备

1. 摄像头 4 根线全部接好再插电脑 USB 口：`5V`、`GND`、`D+`、`D-`（一根不能少；电脑 USB 口自带 5V 供电，杜邦线转接时注意别把 D± 接到 5V 上）
2. ffmpeg：本机已装 ✅（检测到 8.1.2）。换电脑时用 `winget install --id Gyan.FFmpeg -e` 安装

## 运行方式

`.ps1` 双击默认不会运行，用下面任一方式（在 `test` 目录下）：

```
run.bat step1        （依次 step1 ~ step6）
```

或

```
powershell -ExecutionPolicy Bypass -File step1_check_devices.ps1
```

## 步骤与通过标准

| 步骤 | 干什么 | 通过标准 |
|---|---|---|
| `step1` | 枚举摄像头/麦克风/喇叭设备 | 出现一个**不是** Integrated Camera 的摄像头 + 名字带 USB Audio 的麦克风和扬声器 |
| `step2` | 列出摄像头支持的格式 | 有一行 `vcodec=mjpeg min s=1280x720 fps=30`（**记下来**，ESP32 阶段就请求这个格式） |
| `step3` | 拍一张 720p 照片并自动打开 | `output/snap_*.jpg` 清晰、不花屏、颜色正常 |
| `step4` | 打开实时预览 + 实测帧率 | 预览流畅；命令行报出的实际帧率 ≥ 20fps |
| `step5` | 录 5 秒麦克风并回放 | 能听到自己的声音（板上 2Pin 座没插麦克风时是静音，**不算摄像头坏**） |
| `step6` | 往喇叭放 3 秒 440Hz 哔声 | 先在 设置→系统→声音→输出设备 里选 USB 喇叭，然后能听到哔声 |

测完把 `step2` 的完整输出发给我，ESP32 取流要按它列出的格式来请求。

## 故障排查

| 现象 | 可能原因 |
|---|---|
| step1 完全没有新设备 | 4 根线没接全 / D+ D- 接反 / 转接线太长或接触不良 |
| 有摄像头但 step5/6 找不到 USB 音频 | 三合一的麦克风、喇叭是插在板上 2Pin 座的，没插就没有音频端点 |
| 拍照花屏/绿屏/横条 | USB 带宽不够：换电脑直连的 USB 口（别过 Hub），或换短一点的线 |
| step3 提示不支持 1280x720 | 看 step2 输出里实际支持哪些分辨率，改用 `run.bat step3 640 480` 传入宽高 |
